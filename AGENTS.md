# NEZU Arca · publicaciones — guía para agentes

Este repositorio es público. Solo publica archivos descargables firmados de NEZU Arca (hoy, el Kit del servidor Linux en
la release `team-server-kit`).

- Ningún archivo se publica sin la firma Ed25519 de NEZU y sin autorización explícita del responsable.
- No se suben al repositorio ni a una release: datos de clientes o de NEZU, nombres de plataformas o servicios que use
  NEZU, logos, rutas con nombres de usuario, direcciones internas, correos personales ni capturas de pantalla reales.
- Las claves privadas nunca están aquí; las introduce el operador al firmar.
- El código de la aplicación vive en su repositorio privado; aquí no se añade.
